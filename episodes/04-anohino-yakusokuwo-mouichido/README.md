# 第4作『あの日の約束を、もう一度』

紬と祖母の手帳を読み解き、長く会っていない友人との再会を手伝う。

このフォルダだけで遊び、制作できる単独版です。駅の3Dデータ・人物素材・テストを同梱しています。

## 起動

Node.js 22.13以降を使用します。

~~~sh
npm start
~~~

ブラウザで http://127.0.0.1:4184/ を開いてください。別のポートは npm start -- --port 4190 で指定できます。

追加パッケージのインストールは不要です。1人用の物語と進行保存はブラウザ内で動きます。

## 確認と制作

~~~sh
npm run check
npm test
npm run build
~~~

物語は dist/game/promise-state.js、画面と操作は dist/game/promise.js と promise.css にあります。

npm run build は静的ファイルを build/ に作成します。静的ホスティングには build/ の中身を使用できます。

駅の形・階・通路・地図・列車は protected-map.json で保護しています。自動保存のキーと、これまでのクリア記録は元の作品と共通です。

公開先は登録していません。既存の統合版と完成済みの駅を上書きする操作は含めていません。

元の統合版の識別情報は episode.json に記録しています。人物・3Dライブラリのライセンスは dist/game/avatars/ と dist/vendor/ に同梱しています。
