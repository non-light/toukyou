# 東京駅さんぽ — v0.6

東京駅を参考にした空間を、スマートフォンのブラウザで歩ける非公式の3D散策アプリです。8階層・46スポット・14か所の改札・29か所の上下接続に加え、14のホームエリアに代表的な停車電車を配置しています。銀の鈴など、東京駅の待ち合わせの目印4か所も散策できます。

v0.4では、[新宿さんぽ](https://shinjuku-station-walk-non.coatedant.chatgpt.site/)の地図・現在地・改札一覧の操作を参考に、東京版の案内画面を整えました。駅の構造や改札名には東京駅のデータを使っています。

## 待ち合わせの目印（v0.6）

銀の鈴を含む4か所を、3Dの目印・地図・現在地表示・散策地点に追加しました。スマートフォンでは左下の2×2メニューから「待ち合わせ」を開けます。案内画面の同名タブにも一覧があり、目印を選ぶと地図上の位置と説明が開きます。「ここから歩く」を押すと目印の前から散策を始められます。一覧や地図で選択しただけでは移動しません。

| 目印 | 所在階と改札内外 | 模型の特徴 |
| --- | --- | --- |
| 銀の鈴 | B1F・八重洲地下中央口付近の在来線改札内 | 大きな銀色の鈴、吊り輪、ガラスケース、周囲の待合空間 |
| 動輪の広場 | B1F・丸の内地下南口の改札外 | C62-15型蒸気機関車の3つの動輪と連結棒 |
| SQUARE ZERO（スクエア ゼロ） | B1F・グランスタ東京の在来線改札内 | 吹き抜けと3基の縦長サイネージ「モノリス」 |
| 赤レンガ駅舎型ポスト | 1F・丸の内中央口の改札内 | レンガ模様のポストと駅舎ドーム型の飾り |

地図では目印を菱形で表示します。近くまで歩くと現在地名も目印に合わせて切り替わり、改札内・改札外を区別します。各目印の紹介から公式案内も開けます。

配置は所在階・丸の内／八重洲側・改札内外を参考にしていますが、形状、寸法、目印同士の距離や通路の形は散策用に簡略化した模型です。グランスタ全店舗や実際の売場・イベント内容を再現したものではありません。既存の8階層、29か所の上下接続、14改札、14編成の電車も引き続き利用できます。

## 地図・現在地・改札

- 右上のミニマップは現在階を表示します。白い縁の赤い丸が現在地、赤い扇形が見ている方向です。
- 「この階の地図」から現在階の構内マップを開けます。現在地名・階・改札内外の表示は散策位置に合わせて更新します。
- 地図の「立体」と各階タブは閲覧用です。別の階を選んでもプレイヤーは移動しません。異なる階の地図には現在地マーカーを表示しません。
- 平面図は北を上に表示し、在来線・JR東日本新幹線・東海道／山陽新幹線・京葉線・総武線を色分けします。地図を拡大・縮小したり、ドラッグして見渡せます。
- 改札一覧の14か所を路線・改札名・行き先で検索できます。選択すると同じ階の地図と詳細が開き、「ここから歩く」でその改札前から散策を始められます。
- 地図の四角い改札マーク、菱形の待ち合わせ目印、丸い散策地点も選択できます。地点の選択だけでは移動せず、詳細の「ここから歩く」で移動します。
- 改札に近づくと扉が開き、改札機の間を歩いて通過できます。通過時には入場・出場・新幹線のりかえを案内し、現在地の改札内外表示も切り替わります。

この現在地はモデル内の歩行位置です。GPS測位や実際の駅構内での位置案内ではありません。地図と3Dは同じ散策用の座標データを使っています。

14か所の内訳は、1Fの丸の内3改札・八重洲3改札・JR東日本新幹線の北／南のりかえ口・東海道／山陽新幹線の中央／南のりかえ口、B1Fの丸の内地下中央口・八重洲地下中央口、B2Fの京葉地下丸の内口・京葉地下八重洲口です。東京駅に実在するすべての改札を収録したものではありません。八重洲側の在来線改札と、東海道／山陽新幹線に直接入る同名の改札は区別しています。

北陸新幹線は、東北・山形・秋田・北海道・上越と共通のJR東日本側の改札を利用する区分です。「北陸専用改札」は作っていません。東海道／山陽新幹線とは改札・表示・解説を分けています。

## 操作

- 指でスワイプして見回し、左下のスティックで移動します。
- 左下の「歩く／走る」で移動モードを切り替えます。設定では歩く速さ・走る速さを別々に3段階から選べます。
- PCではマウスドラッグとWASD・矢印キーを使えます。Shiftを押している間は一時的に走ります。キー解除・画面離脱時には一時入力を解除します。
- 階段・エレベーターの近くでは上下移動ボタン、またはPCのEキーで別の階へ移動します。地図でスポットを選び「ここから歩く」を押すと、その地点から散策を始められます。
- ガイド散策、地点の解説、天井を見上げる操作、PNG写真保存に対応します。
- 画質・視点の感度・合成環境音を設定できます。

新規設定の標準速度は歩行2.8、走行6（モデル内の距離単位／秒）です。自由散策とガイド散策は同じ速度設定を使います。モード・速度・距離・訪問スポットを端末内に保存します。階の切替中は移動入力を解除し、カメラの高さを移動先に合わせます。

## 階層と京葉ルート

| 階 | 対象エリア |
| --- | --- |
| 2F | 在来線1〜10番線、新幹線14〜19・20〜23番線 |
| M2F | 新幹線ホームへの分離した中間連絡階、八重洲北側中間階 |
| 1F | 丸の内・八重洲改札、北・中央・南通路、新幹線乗換口 |
| B1F | 本駅舎の地下通路と、独立した京葉線連絡通路・動く歩道 |
| B2F | 京葉地下丸の内口・京葉地下八重洲口、改札コンコース |
| B3F | 京葉線の中間コンコース |
| B4F | 南側の京葉線地下1〜4番線、別エリアの総武地下コンコース |
| B5F | 総武快速線・横須賀線の地下1〜4番線 |

京葉線は1F南側 → B1F連絡通路 → B2F → B3F → B4F。総武・横須賀線は本駅舎B1F → B4F総武地下コンコース → B5Fです。同じB1F／B4Fでも離れたエリアを直接つなぎません。M2Fや各ホームも独立した島として表現しています。地図では同じ階の複数エリアを見比べられ、ミニマップは現在のエリアに合わせて表示します。

ガイドも明示した階間接続をたどります。3Dは選択中の階を表示する断面方式です。京葉B1Fの動く歩道は2方向に動き、対応する帯に立つと移動します。

## モデルの精度

写真・LiDAR・現地測量による精密再現ではありません。丸の内が西、八重洲が東という位置関係、北・中央・南の通路、公式の改札名・路線区分・ホーム番号・階層を参考にした模式モデルです。高さ、寸法、距離、階段、設備、店舗、改札間の接続形状や内装は体験用に簡略化した創作表現です。実際の駅の経路案内には使えません。

Googleマップでは駅と周辺の位置関係を参照し、階の区分と接続は鉄道会社の構内図で照合しました。精密再現には、利用可能な実測図面、現地写真、360度撮影・3Dスキャン等を用いたモデルと材質の制作が必要です。JR東日本・JR東海の公式アプリではありません。

## ローカル起動

ビルドや依存関係のインストールは不要です。Python 3を利用する場合：

```sh
python3 -m http.server 4173 --directory dist
```

`http://localhost:4173` をWebGL 2対応ブラウザで開きます。PWA用アイコン・マニフェスト・オフラインキャッシュを同梱しています。ホーム画面追加・オフライン利用には対応ブラウザでHTTPSから初回アクセスしてください。外部Webフォントが使えないときは端末内フォントを使用します。

